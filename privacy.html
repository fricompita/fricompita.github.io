Privacy Policy

Last updated: November 13, 2026

MyAutoUploader ("the App") is a personal desktop tool that uploads videos to the user's own TikTok account via the official TikTok API. This policy explains what data the App handles.

1. Data We Access

  • Basic TikTok profile info (open ID, display name, avatar) via the user.info.basic scope, used only to show which account is connected.
  • Access and refresh tokens issued by TikTok, used only to upload and publish videos on the user's behalf.
  • Video files and captions the user chooses to upload.

2. How Data Is Stored

All data stays on the user's own computer. Tokens are stored locally and are never sent to any server other than TikTok's official API. The App does not run any backend server and does not collect analytics.

3. Data Sharing

We do not sell, share, or transfer any user data to third parties. Videos and captions are sent only to TikTok, at the user's request.

4. Data Deletion

Users can delete all locally stored data at any time by deleting the App's token file, and can revoke the App's access from the TikTok app (Settings and privacy → Security → Apps and services permissions).

5. Changes

This policy may be updated from time to time. Changes will be posted on this page.

6. Contact

Questions about this policy can be sent via the contact information on this website.
